# React Todo List App

## Overview
This is a simple React Todo List application built with **functional components** and **hooks**. Users can:
- Add new todos
- Mark todos as completed
- Delete todos
- Filter todos (All/Active/Completed)

## Features
- **React Fundamentals**: Components, JSX, props, state
- **Functional Components & Hooks**: `useState`, `useEffect`
- **LocalStorage Persistence**: Todos are saved between sessions
- **Responsive Design**: Works on desktop and mobile
- **TypeScript**: Strongly typed components
